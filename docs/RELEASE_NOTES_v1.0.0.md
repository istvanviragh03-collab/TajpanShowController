# Tajpán Show Controller v1.0.0

First stable release.

- Self-contained Windows x64 playback application
- RS-485 Remote support and hardware playback controls
- Remote LCD track, time and playback-state synchronization
- Automatic connection and reconnection
- Playlist loading, saving, persistence and reordering
- Playback seeking and volume control
- Communication diagnostics for port, polling, last response, RTT and errors

No separate .NET runtime installation is required. Download and extract the release ZIP, then run `TajpanShowController.exe`.
