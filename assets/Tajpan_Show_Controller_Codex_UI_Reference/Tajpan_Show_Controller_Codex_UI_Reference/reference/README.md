# Visual reference

Open `index.html` in a normal desktop browser. This is the exact self-contained visual prototype supplied to Codex for implementation mapping.

The HTML is not production code and must not be embedded in the WPF application. Recreate the layout natively in WPF/XAML.

The included `assets/taipan-logo-reference.svg` keeps this standalone HTML reference self-contained. In the actual application, prefer the original Tajpán logo asset already present in the existing project/repository.
