# Visual acceptance checklist

- [ ] Window title/product branding says `Tajpán Show Controller`.
- [ ] Existing original Tajpán logo is reused if present in the repository.
- [ ] Target layout is desktop-first and clean at 1920×1080 / 100% scaling.
- [ ] Playback / Settings / Remote Debug tabs are visually inside the header, not floating below it.
- [ ] Playlist is the dominant panel.
- [ ] Playlist has title + file path + New/Open/Save/Save As.
- [ ] Playlist rows show drag handle + generated sequence + actual filename + duration.
- [ ] Drag reorder updates generated sequence numbers.
- [ ] Sequence number is not parsed from the filename.
- [ ] No separate Project page.
- [ ] No Queue feature.
- [ ] No Prepare feature.
- [ ] Playback panel stays compact.
- [ ] Player shows filename, elapsed/total, thin progress and four transport controls only.
- [ ] Drummer display is character-LCD styled and contains no graphical progress bar.
- [ ] LCD sequence number and filename are independently sourced values.
- [ ] Main Audio card is minimal: health, L/R meter, device name.
- [ ] Main Remote card is minimal: ONLINE/OFFLINE/FAULT + short health line.
- [ ] Detailed remote telemetry is kept on Remote Debug, not Playback.
- [ ] Settings contains Audio, Remote/RS-485, Playback, Playlist, Application sections/subpages.
- [ ] Dark graphite surfaces, subtle borders, red Tajpán accent and green healthy indicators match the reference.
- [ ] No mobile-style stacking or oversized hero sections are introduced.
- [ ] Existing playback/remote/persistence logic remains intact and is bound into the new views.
